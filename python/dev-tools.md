# Инструменты разработчика: ошибки, REPL, traceback

[← CPython без GIL](free-threading-jit.md) · [🏠 Домой](../README.md)

---

- Более точные сообщения об ошибках (`python 3.10-3.11`) — трейсбеки стали
  заметно информативнее: точно указывают, какой атрибут/индекс привёл к
  ошибке (включая выражения в несколько строк), а `NameError`/`AttributeError`
  подсказывают опечатки ("Did you mean...?").
- Улучшенный REPL (`python 3.13+`) — многострочное редактирование,
  подсветка синтаксиса прямо "из коробки" (написан на чистом python, аналог
  `PyPy`-шного REPL).
- Цветной вывод traceback'ов по умолчанию (`python 3.13+`) — можно
  отключить через `PYTHON_COLORS=0` / `NO_COLOR`.
