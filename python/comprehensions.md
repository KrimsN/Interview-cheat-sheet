## Какие бывают comprehensions и чем от них отличается генераторное выражение?

**Коротко.** Списковый, множественный и словарный comprehension строят готовую
коллекцию целиком и сразу. Генераторное выражение в круглых скобках ничего не
строит — это ленивый итератор, который выдаёт элементы по одному.

```python
[x * x for x in range(5)]            # [0, 1, 4, 9, 16]     список
{x * x for x in range(5)}            # {0, 1, 4, 9, 16}     множество
{x: x * x for x in range(3)}         # {0: 0, 1: 1, 2: 4}   словарь
(x * x for x in range(5))            # <generator object ...> ленивый
```

«Кортежного comprehension» не существует: круглые скобки уже заняты
генераторным выражением. Кортеж получают явно — `tuple(x for x in ...)`.

**Подвох.** Разница в памяти — не стилистическая:

```python
import sys
sys.getsizeof([x for x in range(100_000)])   # 800984 байт
sys.getsizeof(x for x in range(100_000))     # 192 байта
```

Генератор хранит только состояние вычисления. Но пройти по нему можно
один раз:

```python
g = (x * x for x in range(5))
sum(g)   # 30
sum(g)   # 0 — генератор уже исчерпан
```

**Глубже.** Если генераторное выражение — единственный аргумент вызова,
скобки можно не дублировать: `sum(x * x for x in range(5))`, `any(n > 2 for n
in nums)`. С `any`/`all` это ещё и короткое замыкание — перебор останавливается
на первом подходящем элементе.

## Как читать вложенные comprehensions?

**Коротко.** `for`-части идут слева направо в том же порядке, что во вложенных
циклах, а выражение результата стоит первым. Два `for` подряд — это плоское
разворачивание, а вложенный comprehension внутри выражения — сохранение
вложенности.

```python
matrix = [[1, 2], [3, 4]]

[x for row in matrix for x in row]        # [1, 2, 3, 4]      разворачивание
[[y for y in row] for row in matrix]      # [[1, 2], [3, 4]]  копия структуры
```

Условие после `for` — фильтр (элементы отбрасываются), условие перед `for` —
это тернарный оператор, он обязан иметь `else`:

```python
[x for x in range(6) if x % 2 == 0]              # [0, 2, 4]        фильтр
[x if x % 2 == 0 else -x for x in range(6)]      # [0,-1,2,-3,4,-5] замена
```

**Подвох.** Читаемость — часть ответа. Comprehension на три `for` и два `if`
формально валиден, но на ревью его просят переписать циклом. Практическая
граница — один `for` плюс один `if`.

## Утекает ли переменная цикла наружу?

**Коротко.** Нет. У comprehension собственная область видимости — это одно из
отличий Python 3 от Python 2, где переменная списочного comprehension затирала
внешнее имя.

```python
[x for x in range(3)]
x
# NameError: name 'x' is not defined
```

**Глубже.** До Python 3.11 comprehension компилировался в отдельную неявную
функцию, которая вызывалась на месте, — отсюда и своя область видимости, и
заметные накладные расходы на вызов. PEP 709 (Python 3.12) заинлайнил
списочные, словарные и множественные comprehensions прямо в вызывающий код:
работают они теперь примерно вдвое быстрее, а изоляция имён сохранена
на уровне компилятора. Генераторные выражения инлайну не подверглись — они
по своей природе остаются отдельным фреймом.
