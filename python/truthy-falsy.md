## Какие объекты считаются ложными?

**Коротко.** По умолчанию любой объект истинный. Ложны только «пустота» и нули —
и этот список конечен, его стоит помнить наизусть.

Ложными считаются:

| Категория | Значения |
|---|---|
| Константы | `False`, `None` |
| Нули | `0`, `0.0`, `0j`, `Decimal(0)`, `Fraction(0, 1)` |
| Пустые коллекции | `''`, `[]`, `()`, `{}`, `set()`, `range(0)` |

Всё остальное истинно — включая `"0"`, `"False"`, `[0]`, `{}` с любым
содержимым и объекты пользовательских классов.

```python
bool("0")      # True  — непустая строка
bool([0])      # True  — непустой список
bool(0.0)      # False
```

**Подвох.** Проверка `if x:` и проверка `if x is not None:` — не одно и то же.
Для `x = 0` или `x = []` первая ложна, вторая истинна. Когда нужно отличить
«значения нет» от «значение ложное», всегда пишут явное сравнение с `None`.

## Как объект решает, истинный он или ложный?

**Коротко.** Интерпретатор ищет `__bool__`, а если его нет — `__len__`. Если нет
ни того, ни другого, объект истинен.

```python
class Empty:
    def __len__(self): return 0

class Weird:
    def __len__(self): return 0
    def __bool__(self): return True

bool(Empty())    # False — сработал __len__
bool(Weird())    # True  — __bool__ имеет приоритет
```

**Подвох.** Приоритет `__bool__` над `__len__` — это и есть вопрос-ловушка:
объект может быть «пустым» по длине и при этом истинным. Реальный пример —
объекты, у которых пустота не означает бессмысленность.

**Глубже.** Некоторые библиотеки намеренно запрещают приведение к `bool`, чтобы
не давать двусмысленный ответ. Массив NumPy из нескольких элементов на `if arr:`
выбросит `ValueError: The truth value of an array with more than one element is
ambiguous` — потому что непонятно, имелось в виду «любой» или «все». Там пишут
`arr.any()` / `arr.all()`.

## Чем `if x:` отличается от `if bool(x):`?

Ничем по результату — но `bool(x)` вычисляется явно и возвращает настоящий
`bool`. Операторы `and`/`or` при этом возвращают **операнд**, а не `bool` — это
разобрано в разделе [bool](bool.md).
