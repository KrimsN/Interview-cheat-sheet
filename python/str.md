## Что такое `str` и чем он отличается от `bytes`?

**Коротко.** `str` — неизменяемая последовательность символов Unicode.
`bytes` — неизменяемая последовательность байтов. Между ними переходят явно:
`encode()` в байты, `decode()` обратно.

```python
'abc'.encode()              # b'abc'          — по умолчанию UTF-8
b'abc'.decode()             # 'abc'
len('\N{SNOWMAN}')          # 1  — один символ
len('\N{SNOWMAN}'.encode()) # 3  — три байта в UTF-8
```

Правило, которое стоит держать в голове: внутри программы — `str`, на границах
(файлы, сеть, БД) — `bytes` с явно указанной кодировкой.

**Подвох.** `str` неизменяем, поэтому сборка строки в цикле через `s += x` на
каждом шаге создаёт новый объект. Для этого есть `''.join(parts)` — линейная
сложность вместо квадратичной.

## Как строка хранится в памяти?

**Коротко.** Гибко: CPython выбирает ширину символа по самому «широкому» символу
в строке — 1, 2 или 4 байта (PEP 393).

Если в строке только ASCII/Latin-1, на символ уходит один байт. Появился хотя бы
один символ из более широкого диапазона — вся строка переходит на UCS-2 или
UCS-4:

```python
import sys
sys.getsizeof('a' * 10)          # 51  — один байт на символ
sys.getsizeof('\U0001F642' + 'a' * 9)   # 100 — четыре байта на символ
```

**Подвох.** Частое заблуждение — «строки внутри хранятся в UTF-8». Нет: UTF-8
используется при кодировании и декодировании, а также как кеш для C API
(`PyUnicode_AsUTF8`), но не как единственное внутреннее представление. Именно
благодаря фиксированной ширине индексация `s[i]` работает за константное время.

## Что нового в f-строках?

**Коротко.** `python 3.12+` (PEP 701) снял ограничения на кавычки и вложенность.

```python
# python 3.12+
name = "world"
print(f"{"hello"} {name}")      # раньше было SyntaxError
print(f"{f"{name.upper()}"}")   # вложенные f-строки
```

Полезный отладочный синтаксис - `=` внутри подстановки, печатает и выражение, и
значение:

```python
a = 5
f"{a = }"      # 'a = 5'
```

Модификаторы форматирования:

| Модификатор  | Что делает                                        | Пример                                   |
| ------------ | ------------------------------------------------- | ---------------------------------------- |
| `<`          | Выравнивание по левому краю                       | `>>>f"{123:<5}"`<br>`'123 '`             |
| `>`          | Выравнивание по правому краю                      | `>>>f"{123:>5}"`<br>`' 123'`             |
| `^`          | Выравнивание по центру                            | `>>>f"{123:^5}"`<br>`' 123 '`            |
| `=`          | Размещает знак перед символами заполнения         | `>>>f"{-123:=+7}"`<br>`'- 123'`          |
| `+`          | Всегда показывает знак числа                      | `>>>f"{123:+}"`<br>`'+123'`              |
| `-`          | Показывает минус только для отрицательных чисел   | `>>>f"{123:-}"`<br>`'123'`               |
| пробел       | Добавляет пробел перед положительным числом       | `>>>f"{123: }"`<br>`' 123'`              |
| `#`          | Включает альтернативную форму представления       | `>>>f"{10:#b}"`<br>`'0b1010'`            |
| `0`          | Заполняет число нулями                            | `>>>f"{123:05}"`<br>`'00123'`            |
| `width`      | Задаёт минимальную ширину поля                    | `>>>f"{123:8}"`<br>`' 123'`              |
| `.precision` | Задаёт точность или максимальную длину            | `>>>f"{3.14159:.2f}"`<br>`'3.14'`        |
| `,`          | Разделяет разряды запятыми                        | `>>>f"{1000000:,}"`<br>`'1,000,000'`     |
| `_`          | Разделяет разряды подчёркиваниями                 | `>>>f"{1000000:_}"`<br>`'1_000_000'`     |
| `b`          | Двоичная система счисления                        | `>>>f"{10:b}"`<br>`'1010'`               |
| `c`          | Преобразует число в Unicode-символ                | `>>>f"{65:c}"`<br>`'A'`                  |
| `d`          | Десятичное целое число                            | `>>>f"{123:d}"`<br>`'123'`               |
| `o`          | Восьмеричная система счисления                    | `>>>f"{10:o}"`<br>`'12'`                 |
| `x`          | Шестнадцатеричная система (нижний регистр)        | `>>>f"{255:x}"`<br>`'ff'`                |
| `X`          | Шестнадцатеричная система (верхний регистр)       | `>>>f"{255:X}"`<br>`'FF'`                |
| `n`          | Локализованный числовой формат                    | `>>>f"{1000000:n}"`<br>зависит от локали |
| `e`          | Экспоненциальная запись                           | `>>>f"{1000:e}"`<br>`'1.000000e+03'`     |
| `E`          | Экспоненциальная запись (верхний регистр)         | `>>>f"{1000:E}"`<br>`'1.000000E+03'`     |
| `f`          | Десятичное число с фиксированной точностью        | `>>>f"{3.14:f}"`<br>`'3.140000'`         |
| `f`          | Как `f`, но `INF` и `NAN` в верхнем регистре      | `>>>f"{float('inf'):F}"`<br>`'INF'`      |
| `g`          | Общий формат (автоматически `f` или `e`)          | `>>>f"{1234.5:g}"`<br>`'1234.5'`         |
| `G`          | Общий формат с заглавной экспонентой              | `>>>f"{1234.5:G}"`<br>`'1234.5'`         |
| `%`          | Умножает число на 100 и добавляет `%`             | `>>>f"{0.25:%}"`<br>`'25.000000%'`       |
| `s`          | Строковое представление                           | `>>>f"{'Python':s}"`<br>`'Python'`       |
| `=`          | Debug-синтаксис: выводит выражение и его значение | `>>>f"{2 + 2=}"`<br>`'2 + 2=4'`          |
Конверторы:

| Конвертер | Что делает                     | Пример                                                               |
| --------- | ------------------------------ | -------------------------------------------------------------------- |
| `!s`      | Преобразование через `str()`   | `>>>f"{a!s}"`<br>`'10'`                                              |
| `!r`      | Преобразование через `repr()`  | `>>>f"{a!r}"`<br>`'<class A> val = 10 штук'`                         |
| `!a`      | Преобразование через `ascii()` | `>>>f"{a!a}"`<br>`'<class A> val = 10 \\u0448\\u0442\\u0443\\u043a'` |
> В примерах используется экземпляр пользовательского класса:
> ```python
>>> class A:
...     def __init__(self, val):
...         self.val= val
...     def __str__(self):
...         return str(self.val)
...     def __repr__(self):
...         return f'<class A> val = {self.val} штук'
...
>>> a = A(10)
> ```


Полный список всех модификаторов и конвертеров и общее описание синтаксиса: [Python Format Specification Mini-Language](https://docs.python.org/3/library/string.html?utm_source=chatgpt.com#format-specification-mini-language)

## Что такое t-строки?

**Коротко.** `python 3.14+` (PEP 750) — литерал `t"..."`, который возвращает не
готовую строку, а объект `string.templatelib.Template` со **структурой**:
отдельно статические куски, отдельно подставленные значения.

```python
# python 3.14+
name = "world"
t = t"Hello, {name}!"
t.strings          # ('Hello, ', '!')
t.interpolations   # (Interpolation(value='world', expression='name', ...),)
```

Смысл в безопасности: значения не подставляются «вслепую», их можно сначала
обработать — экранировать под SQL, HTML или shell — и только потом собрать
строку. Это тот же подход, что у параметризованных запросов, но на уровне языка.

**Подвох.** t-строка — не строка: `str(t)` не даст ожидаемого результата,
и передать её туда, где ждут `str`, нельзя. Её должен обработать код, знающий
про `Template`.
