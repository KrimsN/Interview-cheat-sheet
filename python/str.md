# str

---

Строка | текстовая последовательность - тип данных для строковых значений.
Содержит последовательность символов Unicode. Внутреннее представление —
гибкое (PEP 393): CPython выбирает ширину символа (Latin-1 / UCS-2 / UCS-4)
по самому "широкому" символу в строке, а не хранит строку в UTF-8 постоянно.
UTF-8 используется при кодировании/декодировании (файлы, сеть) и как
кеш для `PyUnicode_AsUTF8`, но не как единственное внутреннее представление.

Остальное смотри в [документации](https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str)

**f-строки без ограничений на вложенность и кавычки** (`python 3.12+`, PEP
701) — внутри f-строк теперь можно переиспользовать те же кавычки, писать
многострочные выражения и вложенные f-строки:

```python
# python 3.12+
name = "world"
print(f"{"hello"} {name}")          # раньше было SyntaxError
print(f"{f"{name.upper()}"}")       # вложенные f-строки
```

**Template strings (t-строки)** (`python 3.14+`, PEP 750) — литерал
`t"..."`, синтаксически похожий на f-строку, но вместо `str` возвращающий
объект `string.templatelib.Template`: структурированные данные (статические
куски + подставленные значения), которые сначала можно безопасно обработать
(экранировать под SQL/HTML/shell) и только потом собрать в строку. В отличие
от f-строк, значения не подставляются "вслепую":

```python
# python 3.14+
name = "world"
t = t"Hello, {name}!"
# t.strings -> ('Hello, ', '!')
# t.interpolations -> (Interpolation(value='world', expression='name', ...),)
```
