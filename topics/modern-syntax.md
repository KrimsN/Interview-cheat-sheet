# Синтаксис 3.8: walrus-оператор, позиционно-только параметры

python.md уже хорошо покрывает версионные фичи 3.10-3.14 (см. оглавление
файла), но синтаксис Python 3.8 остался за скобками — а он до сих пор часто
встречается в вопросах на собеседовании, так как это одна из самых заметных
фич последних лет.

## Что нужно знать

- **Walrus-оператор `:=`** (PEP 572, python 3.8+) — присваивание как часть
  выражения, а не отдельная инструкция. Позволяет одновременно вычислить
  и сохранить значение прямо в условии/comprehension, избегая повторного
  вызова:

  ```python
  # python 3.8+
  if (n := len(data)) > 10:
      print(f"слишком много элементов: {n}")

  # полезно в comprehension, чтобы не вычислять функцию дважды
  results = [y for x in data if (y := expensive(x)) is not None]
  ```

  Ограничение: `:=` нельзя использовать напрямую как именованный
  (keyword) аргумент вызова — только как позиционный аргумент или в
  условии/выражении.

- **Позиционно-только параметры `/`** (PEP 570, python 3.8+) — всё, что
  стоит до `/` в сигнатуре функции, можно передавать только позиционно,
  без указания имени параметра:

  ```python
  # python 3.8+
  def f(a, b, /, c, d, *, e, f):
      ...

  # a, b — только позиционно
  # c, d — позиционно или по имени
  # e, f — только по имени (keyword-only, привычный синтаксис через *)
  ```

  Используется в основном в стандартной библиотеке и API-дизайне: имена
  `a`/`b` можно свободно переименовать в будущей версии, не ломая обратную
  совместимость для вызывающего кода (раз извне на них нельзя сослаться по
  имени).
