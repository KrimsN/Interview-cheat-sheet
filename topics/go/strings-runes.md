# Go: строки, байты, руны

[🏠 Карта тем по Go](README.md)

## Что нужно знать

- **Строка — неизменяемый срез байтов в UTF-8**, а не последовательность
  символов. `len(s)` возвращает **количество байтов**, не символов;
  `utf8.RuneCountInString(s)` — количество рун.
- **Индексирование `s[i]` даёт `byte`**, а `for i, r := range s` итерирует по
  рунам, где `i` — байтовый индекс начала руны. Самый частый вопрос про строки
  на собеседовании.
- **Руна** — это `int32`, кодовая точка Unicode. Руна ≠ «символ» в бытовом
  смысле: emoji с модификаторами и комбинирующие диакритики состоят из
  нескольких рун (grapheme cluster). Реверс строки «по рунам» ломает такие
  случаи — хороший развёрнутый ответ на задачу «переверни строку».
- **Конверсии `[]byte(s)` и `[]rune(s)` копируют данные** (аллокация).
  Компилятор оптимизирует часть случаев — `for range []byte(s)`, поиск в карте
  по `string(bytes)`, конкатенацию в сравнении.
- **Конкатенация в цикле `s += x` квадратична** по объёму копирования —
  идиоматично `strings.Builder` (или `bytes.Buffer`) с `Grow()` при известном
  размере.
- **Ключевые пакеты**: `strings` (`Split`, `Join`, `Contains`, `Cut`,
  `TrimSpace`, `Builder`, `Replacer`), `strconv` (`Atoi`, `Itoa`, `ParseFloat`,
  `Quote` — быстрее, чем `fmt.Sprintf`), `unicode`, `unicode/utf8`, `bytes` —
  зеркало `strings` для `[]byte`.
- **`strings.Cut`** — современная идиома вместо `SplitN(s, sep, 2)`.
- **Сравнение и нормализация**: `strings.EqualFold` для регистронезависимого
  сравнения; для корректного Unicode-сравнения — `golang.org/x/text`.
- **Форматирование**: глаголы `%v`, `%+v`, `%#v`, `%T`, `%q`, `%w` (последний —
  только в `fmt.Errorf`). `%v` для типа с методом `String()` вызывает его —
  осторожно с бесконечной рекурсией, если внутри `String()` печатать сам тип
  через `%v`.
