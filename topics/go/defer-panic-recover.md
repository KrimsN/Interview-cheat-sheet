# Go: defer, panic, recover

[🏠 Карта тем по Go](README.md)

## Что нужно знать

- **`defer` откладывает вызов до выхода из функции** (не из блока и не из
  итерации цикла). Выполняется в порядке **LIFO** — стек отложенных вызовов.
- **Аргументы `defer` вычисляются в момент объявления**, а тело — при выходе.
  Отсюда классика: `defer fmt.Println(i)` печатает значение на момент `defer`,
  а `defer func() { fmt.Println(i) }()` — на момент выхода.
- **`defer` в цикле** копит вызовы до конца функции — типичная утечка файловых
  дескрипторов. Лечится выносом тела итерации в отдельную функцию (или
  замыкание), либо явным закрытием.
- **`defer` и именованные результаты**: только отложенная функция с доступом к
  именованному результату может **изменить возвращаемое значение** —
  основа идиомы `defer func() { if r := recover(); r != nil { err = ... } }()`
  и «оборачивания ошибки на выходе».
- **Типичные применения**: `defer f.Close()`, `defer mu.Unlock()`,
  `defer rows.Close()`, `defer cancel()` для контекста, замер времени
  `defer trace("name")()`.
- **Ошибку от `Close()` нельзя терять** для записи: при работе на запись
  идиома — `defer func() { err = errors.Join(err, f.Close()) }()`.
- **`defer` дёшев**: с Go 1.14 открытые (open-coded) defer почти бесплатны;
  дорогая ветка остаётся для defer в цикле и в условном коде.
- **`panic`** разворачивает стек, выполняя отложенные вызовы каждой функции;
  если никто не сделал `recover`, процесс падает и печатает стек всех горутин.
- **`recover` работает только при прямом вызове внутри `defer`**. Вызов
  `recover()` в обычном коде или во вложенной функции вернёт `nil`.
- **Panic в горутине не ловится `recover` в родительской функции** — каждая
  горутина восстанавливается сама.
- **`recover` не сбрасывает состояние**: после восстановления объект может
  остаться неконсистентным. Идиома — восстанавливаться на границе запроса и
  завершать эту единицу работы ошибкой.
- **`runtime.Goexit`**, `os.Exit` (defer **не** выполняются!) и фатальные
  ошибки рантайма — знать различия.
