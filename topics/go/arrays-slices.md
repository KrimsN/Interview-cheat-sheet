# Go: массивы и слайсы

[🏠 Карта тем по Go](README.md)

## Что нужно знать

- **Массив `[N]T` — значение фиксированной длины**, длина часть типа: `[3]int`
  и `[4]int` — разные типы. Присваивание и передача в функцию **копируют весь
  массив**. Массивы сравнимы оператором `==`.
- **Слайс — дескриптор из трёх полей**: указатель на массив-хранилище (backing
  array), `len` и `cap`. Сам дескриптор передаётся по значению, но данные
  общие — отсюда все ловушки.
- **`append`**: если `cap` хватает, элементы пишутся в существующий массив
  (мутируя данные, которые видны через другие слайсы); если нет — выделяется
  новый массив, данные копируются, связь со старым теряется. Поэтому
  `append` **обязательно присваивают обратно**: `s = append(s, x)`.
- **Ловушка «слайс от слайса»**: `b := a[1:3]` разделяет хранилище с `a`.
  Запись в `b[0]` меняет `a[1]`, а `append(b, ...)` может затереть `a[3]`.
  Защита — трёхиндексный срез `a[1:3:3]`, который ограничивает `cap`, либо
  явное копирование через `slices.Clone` / `copy`.
- **Утечка памяти через слайс**: маленький слайс, взятый от большого,
  удерживает весь backing array в живых. Если нужен только кусок — копируйте.
  То же с подстрокой большого файла в памяти.
- **`make([]T, len, cap)`** и преаллокация: если размер известен,
  `make([]T, 0, n)` убирает серию перевыделений. Рост capacity — примерно
  удвоение для малых слайсов и коэффициент около 1.25 для больших; точные
  числа не гарантируются спецификацией, и на интервью достаточно сказать
  «амортизированная константа».
- **`copy(dst, src)`** копирует `min(len(dst), len(src))` элементов и
  возвращает их число. Частая ошибка — `copy` в слайс нулевой длины, но
  ненулевой ёмкости: скопируется ноль элементов.
- **Нулевой слайс `var s []T` — это `nil`**, но с ним работают `len`, `cap`,
  `append` и `for range`. `nil`-слайс и пустой `[]T{}` различимы только
  сравнением с `nil` и при сериализации в JSON (`null` против `[]`).
- **Удаление элемента**: `s = append(s[:i], s[i+1:]...)` (порядок сохраняется,
  O(n)) или `s[i] = s[len(s)-1]; s = s[:len(s)-1]` (порядок ломается, O(1)).
  Не забыть занулить «хвост», если элементы — указатели, иначе утечка.
- **Современный пакет `slices`** (Go 1.21+): `Sort`, `SortFunc`, `Contains`,
  `Index`, `Clone`, `Equal`, `BinarySearch`, `Delete`, `Insert`, `Reverse` —
  дженерик-замена ручным циклам и `sort.Slice`.
- **Многомерность**: `[][]T` — слайс слайсов, строки могут быть разной длины
  и выделяются отдельно; для плотной матрицы часто выгоднее один плоский
  слайс с индексом `i*w + j`.
