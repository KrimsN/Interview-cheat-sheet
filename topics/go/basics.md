# Go: базовый синтаксис и модель языка

[🏠 Карта тем по Go](README.md)

## Что нужно знать

- **Философия языка**: маленькая спецификация (читается за вечер), один способ
  форматирования (`gofmt`), явность вместо магии, композиция вместо наследования,
  отсутствие исключений / перегрузки операторов / наследования классов. На
  интервью часто спрашивают «почему в Go нет X» — ответ почти всегда «ради
  простоты компиляции, читаемости и предсказуемости».
- **Объявления**: `var x int`, короткое `x := 42` (только внутри функций),
  `const`, `type`. Множественное присваивание и swap `a, b = b, a`.
- **Zero values**: неинициализированная переменная всегда получает нулевое
  значение — `0`, `""`, `false`, `nil` для указателей, слайсов, карт, каналов,
  интерфейсов и функций. Идиома «полезный нулевой объект»: `var buf bytes.Buffer`
  и `var mu sync.Mutex` готовы к работе без конструктора.
- **`iota`** — счётчик внутри блока `const`, идиоматический способ объявить
  перечисление; сбрасывается на каждом новом `const (`.
- **Экспорт по регистру**: идентификатор с заглавной буквы виден снаружи пакета,
  со строчной — нет. Никаких `public` / `private`.
- **Управляющие конструкции**: только `for` (три формы плюс `for range`),
  `switch` без «проваливания» (нужен явный `fallthrough`), `switch` без
  выражения как замена цепочки `if / else if`, метки и `break label` /
  `continue label`.
- **`for range`**: по слайсу отдаёт индекс и копию значения, по карте — ключ и
  значение в случайном порядке, по строке — байтовый индекс и руну, по каналу —
  значения до закрытия. **Начиная с Go 1.22 переменная цикла создаётся заново на
  каждой итерации**, поэтому классическая ловушка с захватом переменной в
  горутине на новых версиях не срабатывает — но на интервью её всё ещё
  спрашивают, и ответ «зависит от версии» здесь правильный.
- **Функции**: несколько возвращаемых значений, именованные результаты (и
  понимание, когда они вредят читаемости), variadic-параметры `...T` и
  раскрытие `slice...`, функции как значения, замыкания.
- **Указатели есть, арифметики указателей нет.** `new(T)` возвращает `*T`,
  `&T{...}` идиоматичнее. Разыменование для полей и методов неявное.
- **Всё передаётся по значению.** Слайсы, карты и каналы — небольшие
  структуры-дескрипторы, поэтому копия «видит» те же данные; отсюда путаница
  «в Go есть ссылочные типы». Ссылок в смысле C++ в языке нет.

## Ссылки

- [A Tour of Go](https://go.dev/tour/) — интерактивный тур, минимальный вход в синтаксис.
- [The Go Programming Language Specification](https://go.dev/ref/spec) — короткая и читаемая спецификация, источник истины по семантике.
- [Effective Go](https://go.dev/doc/effective_go) — канонический документ об идиомах языка.
- [Go by Example](https://gobyexample.com/) — быстрый справочник «как это пишется» по каждой конструкции.
- [Go Proverbs](https://go-proverbs.github.io/) — поговорки Роба Пайка, объясняющие дизайн-решения языка.
- [Fixing For Loops in Go 1.22](https://go.dev/blog/loopvar-preview) — что именно изменилось в семантике переменной цикла.
