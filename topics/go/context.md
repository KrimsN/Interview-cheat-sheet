# Go: context.Context

[🏠 Карта тем по Go](README.md)

## Что нужно знать

- **Зачем**: сквозная отмена, дедлайны и передача request-scoped значений через
  границы горутин и API. Контекст — это дерево: отмена родителя отменяет всех
  потомков.
- **Конструкторы**: `context.Background()` (корень в `main`, инициализации,
  тестах), `context.TODO()` (заглушка, когда контекст ещё не протянут),
  `WithCancel`, `WithTimeout`, `WithDeadline`, `WithValue`,
  `WithCancelCause` / `context.Cause` (Go 1.20+, причина отмены),
  `WithoutCancel` и `AfterFunc` (Go 1.21+).
- **`cancel` нужно вызывать всегда**, обычно `defer cancel()` — иначе течёт
  таймер и горутина-наблюдатель. `go vet` (`lostcancel`) это ловит.
- **Идиома использования**: `ctx` — **первый параметр** функции, имя `ctx`,
  никогда не хранится в структуре (исключения редки и осознанны), никогда не
  `nil`.
- **`ctx.Done()`** — канал, закрывающийся при отмене; `ctx.Err()` возвращает
  `context.Canceled` или `context.DeadlineExceeded`. Проверять через
  `select` в длинных циклах и при работе с каналами.
- **Отмена — это сигнал, а не принудительная остановка.** Рантайм не убивает
  горутину; код обязан сам проверять `ctx.Done()`. Функция без поддержки
  контекста (например, тяжёлый CPU-цикл или `os.ReadFile`) не прервётся.
- **`context.WithValue`** — только для request-scoped данных (trace id,
  идентификатор пользователя, логгер запроса), **не** для передачи параметров
  и зависимостей. Ключ должен быть неэкспортируемым собственным типом, иначе
  коллизии между пакетами. Поиск значения — линейный проход по цепочке.
- **Дедлайн — свойство запроса**: `WithTimeout` на клиенте HTTP, БД и gRPC;
  дочерний контекст не может продлить дедлайн родителя, только сократить.
- **Интеграция со стандартной библиотекой**: `http.Request.Context()`
  (отменяется при разрыве соединения), `http.NewRequestWithContext`,
  `database/sql` (`QueryContext`, `ExecContext`), `os/exec.CommandContext`.
- **Типовые ошибки**: передача `context.Background()` внутрь обработчика
  вместо запросного; сохранение `ctx` в структуру и переиспользование после
  отмены; отсутствие проверки `ctx.Err()` перед дорогой операцией.
