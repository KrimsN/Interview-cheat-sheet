# Rust: типы, представление в памяти, Sized

[🏠 Карта тем по Rust](README.md)

## Что нужно знать

- **Скалярные типы**: `i8..i128`, `u8..u128`, `isize`/`usize` (размер
  указателя), `f32`/`f64`, `bool`, `char` (скалярное значение Unicode, 4 байта,
  не байт). Неявных числовых преобразований нет — только `as` (усечение) или
  `TryFrom` (проверяемое).
- **Переполнение целых**: в debug-сборке — паника, в release — обёртывание по
  модулю. Это не неопределённое поведение, а два определённых режима. Явные
  варианты: `checked_add`, `saturating_add`, `wrapping_add`,
  `overflowing_add`.
- **Составные типы**: кортежи, массивы `[T; N]` (длина в типе), слайсы `[T]`
  (широкий указатель: адрес + длина), структуры (обычные, кортежные, unit),
  перечисления.
- **Раскладка по умолчанию не определена**: `repr(Rust)` разрешает
  переупорядочивание полей ради упаковки. Для FFI и стабильного ABI —
  `#[repr(C)]`, для перечислений — `#[repr(u8)]` и подобные,
  `#[repr(transparent)]` — для newtype-обёрток.
- **Оптимизация нишей (niche optimization)**: `Option<&T>`, `Option<Box<T>>`,
  `Option<NonZeroU32>` занимают столько же, сколько сам тип, потому что `None`
  кодируется невозможным битовым представлением. Любимый вопрос на «глубже».
- **Enum — это размеченное объединение**: размер равен тегу плюс наибольший
  вариант с учётом выравнивания; большие варианты стоит боксировать
  (`clippy::large_enum_variant`).
- **`Sized` и DST**: типы с неизвестным на этапе компиляции размером (`[T]`,
  `str`, `dyn Trait`) существуют только за указателем — `&[T]`, `Box<str>`,
  `&dyn Trait`. Неявная граница `T: Sized` у каждого параметра типа снимается
  через `T: ?Sized`.
- **Широкие указатели**: `&[T]` — это (адрес, длина), `&dyn Trait` — (адрес,
  указатель на таблицу методов). Отсюда следует, почему `dyn Trait` не
  `Sized` и почему трейт-объект нельзя вернуть по значению без `Box`.
- **Инструменты интроспекции**: `size_of`, `align_of`, `size_of_val`,
  `-Zprint-type-sizes` на nightly.
- **Newtype**: `struct UserId(u64)` — нулевая стоимость в рантайме, но
  отдельный тип для системы типов. Основа приёма «сделай некорректные
  состояния непредставимыми» (см. [идиомы](idioms-api-design.md)).
- **Псевдонимы типов** (`type Result<T> = std::result::Result<T, MyError>;`) —
  не новый тип, а сокращение; проверок не добавляет.
