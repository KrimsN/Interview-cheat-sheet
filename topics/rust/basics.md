# Rust: базовый синтаксис и модель языка

[🏠 Карта тем по Rust](README.md)

## Что нужно знать

- **Позиционирование языка**: системный язык без сборщика мусора и без ручного
  `free`. Безопасность памяти и отсутствие гонок данных проверяются
  **на этапе компиляции** через систему владения. Девиз — «fearless
  concurrency» и «zero-cost abstractions»: абстракция не должна стоить дороже,
  чем написанный вручную эквивалент.
- **Что спрашивают первым**: «зачем Rust, если есть C++/Go». Ответ:
  предсказуемая производительность без GC + статические гарантии памяти и
  потокобезопасности; цена — сложность borrow checker и время компиляции.
- **`let` по умолчанию иммутабелен**, изменяемость явная: `let mut x = 5`.
  Это не константа: `const` вычисляется на этапе компиляции и инлайнится,
  `static` — единственный объект с фиксированным адресом и `'static`-временем
  жизни.
- **Shadowing**: `let x = "5"; let x: i32 = x.parse()?;` — новое связывание с
  тем же именем, возможно с другим типом. Не путать с мутацией.
- **Rust — язык выражений**: `if`, `match`, `loop` и блок `{}` возвращают
  значение; последнее выражение без `;` — результат. Точка с запятой
  превращает выражение в инструкцию со значением `()` (unit).
- **Вывод типов** локальный, но полный внутри функции; сигнатуры функций
  типы всегда указывают явно.
- **Управляющие конструкции**: `if`/`else` (условие строго `bool`, никакой
  «истинности» чисел), `loop` с `break value`, `while`, `while let`,
  `for x in iterable` (всегда через `IntoIterator`), метки циклов `'outer:`.
- **Функции и модули**: `fn`, `mod`, `pub`, `use`; точка входа `fn main()`.
  Именование: `snake_case` для функций и переменных, `CamelCase` для типов,
  `SCREAMING_SNAKE_CASE` для констант — проверяется компилятором как lint.
- **`Option<T>` вместо `null`** и `Result<T, E>` вместо исключений — их видно
  в первый же день, разбор в
  [перечислениях](enums-pattern-matching.md) и [ошибках](error-handling.md).
- **Cargo — часть языка на практике**: `cargo new`, `cargo run`, `cargo test`,
  `Cargo.toml`. Отдельного «мейкфайла» экосистема не знает.
- **Editions** (2015 / 2018 / 2021 / 2024): наборы несовместимых изменений
  синтаксиса, при этом крейты разных изданий линкуются друг с другом. Издание
  2024 стабилизировано в Rust 1.85 (2025) и стало значением по умолчанию для
  новых проектов.
- **Компилятор как учитель**: сообщения `rustc` с номерами ошибок (`E0382`),
  подсказками и `rustc --explain`. На интервью нормально сказать «здесь я бы
  посмотрел, что скажет borrow checker» — это часть рабочего процесса.
