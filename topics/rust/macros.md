# Rust: макросы

[🏠 Карта тем по Rust](README.md)

## Что нужно знать

- **Макросы работают на уровне синтаксического дерева**, а не текста, и
  раскрываются до проверки типов. Отсюда гигиена: идентификаторы из макроса
  не конфликтуют с идентификаторами места вызова.
- **Два семейства**:
  - декларативные `macro_rules!` — сопоставление с образцом по токенам
    (`$x:expr`, `$t:ty`, `$($x:expr),*`), большинство «бытовых» макросов;
  - процедурные — отдельный крейт с `proc-macro = true`, принимает и
    возвращает `TokenStream`; три вида: `#[derive(...)]`, атрибутные
    (`#[tokio::main]`, `#[test]`) и функциональные (`sqlx::query!`).
- **Зачем они нужны**: переменное число аргументов (`vec!`, `println!`),
  кодогенерация по структуре типа (`serde`), DSL и проверки на этапе
  компиляции (`sqlx::query!` проверяет SQL по живой базе).
- **Стандартные макросы, которые надо знать**: `println!`/`format!`/`write!`,
  `vec!`, `assert!`/`assert_eq!`, `matches!`, `todo!`/`unimplemented!`/
  `unreachable!`, `dbg!`, `include_str!`, `env!`, `cfg!`.
- **Форматирование строк** — тоже макрос: захват переменных прямо в строке
  (`println!("{name}")`) появился в Rust 1.58; `{:?}`, `{:#?}`, `{:>8.2}`,
  позиционные и именованные аргументы.
- **Экспорт**: `#[macro_export]` кладёт `macro_rules!`-макрос в корень крейта;
  процедурные макросы живут в отдельном крейте (обычно `foo` +
  `foo-derive`).
- **Инструменты отладки**: `cargo expand` (раскрытие макросов),
  `trace_macros!` на nightly; для proc-macro — крейты `syn`, `quote`,
  `proc-macro2`.
- **Цена**: время компиляции, непрозрачные сообщения об ошибках,
  усложнение чтения. Идиома — сначала функция или трейт, макрос только
  когда без него не выразить.
- **Подвох на интервью**: чем макросы Rust отличаются от макросов C
  (гигиена, работа с AST, отсутствие подстановки текста); почему `println!`
  со скобкой-восклицанием, а не функция (переменное число аргументов и
  проверка формата на этапе компиляции).

## Ссылки

- [Book: Macros](https://doc.rust-lang.org/book/ch20-05-macros.html) — обзор обоих семейств.
- [The Little Book of Rust Macros](https://veykril.github.io/tlborm/) — подробный разбор `macro_rules!`.
- [Rust Reference: Macros](https://doc.rust-lang.org/reference/macros.html) — формальные правила и гигиена.
- [syn](https://docs.rs/syn) и [quote](https://docs.rs/quote) — стандартный инструментарий процедурных макросов.
- [cargo-expand](https://github.com/dtolnay/cargo-expand) — посмотреть, во что раскрывается макрос.
