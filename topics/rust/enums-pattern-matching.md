# Rust: перечисления и сопоставление с образцом

[🏠 Карта тем по Rust](README.md)

## Что нужно знать

- **Enum в Rust — полноценный алгебраический тип-сумма**: каждый вариант может
  нести свои данные (`enum Shape { Circle(f64), Rect { w: f64, h: f64 } }`).
  Это не «именованные константы», как в C, — на этом строится половина
  идиоматики языка.
- **`Option<T>`** заменяет `null`: значение либо есть (`Some`), либо нет
  (`None`), и компилятор заставляет обработать оба случая. Отсюда «в Rust нет
  ошибки на миллиард долларов».
- **`Result<T, E>`** заменяет исключения — подробнее в
  [обработке ошибок](error-handling.md).
- **`match` исчерпывающий**: не покрыл вариант — ошибка компиляции. Добавили
  вариант в enum — компилятор показал все места, где нужно дописать логику.
  Это главный аргумент за enum вместо строковых «типов».
- **Виды образцов**: литералы, диапазоны `1..=9`, деструктуризация структур,
  кортежей, срезов (`[first, .., last]`), вложенные образцы, `|` для
  альтернатив, `_` и `..` для игнорирования, `@` для привязки значения
  (`n @ 1..=9`), guard-условия `if x > 0`.
- **`ref` / `ref mut` и match ergonomics**: современный компилятор сам
  выводит режим связывания при сопоставлении по ссылке, поэтому `ref` в новом
  коде почти не встречается — но в старом коде и на интервью попадается.
- **Сокращённые формы**: `if let`, `while let`, `let ... else` (ранний выход
  без вложенности, стабилен с Rust 1.65), `matches!(x, Pat)` для булевой
  проверки.
- **Комбинаторы вместо ручного match**: `map`, `and_then`, `unwrap_or`,
  `unwrap_or_else`, `unwrap_or_default`, `ok_or`, `filter`, `zip`,
  `take`/`replace`. Идиоматичный код чередует `match` и комбинаторы, а не
  сводится к одному стилю.
- **Enum как конечный автомат**: состояние с данными в вариантах +
  `match` на переход — типовой ответ на вопрос «как в Rust моделируют
  состояния».
- **Подвох**: `Option<&T>` и `&Option<T>` — разные типы (`as_ref()` переводит
  одно в другое); `unwrap` на `None` — паника, в продакшене вместо него
  `expect` с внятным сообщением или полноценная обработка.
- **Нерефутабельные образцы**: `let (a, b) = pair;` — тоже сопоставление;
  `let Some(x) = opt;` не компилируется именно потому, что образец
  опровержимый.
