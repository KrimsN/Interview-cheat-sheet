# Сортировка: `sorted()`, `key`, Timsort

## Что нужно знать

- **`sorted(iterable)` vs `list.sort()`** — `sorted()` возвращает новый
  список и работает с любым iterable, `.sort()` — метод списка, сортирует
  на месте (`in-place`) и возвращает `None` (частая ошибка новичков:
  `l = l.sort()` затирает список на `None`).
- **Параметр `key`** — функция, вычисляющая значение для сравнения по
  каждому элементу (`sorted(people, key=lambda p: p.age)`), вместо
  прямого сравнения элементов. Вычисляется один раз на элемент (а не на
  каждое сравнение), что делает `key` эффективнее, чем кастомный
  `cmp`-компаратор (который был в Python 2 и убран в Python 3).
- **`reverse=True`** — сортировка по убыванию без необходимости
  инвертировать `key`.
- **Timsort** — гибридный алгоритм (Merge Sort + Insertion Sort),
  используемый в `sorted()`/`.sort()`. Разбивает данные на "runs"
  (уже упорядоченные участки), короткие runs досортировывает Insertion
  Sort'ом (эффективен на почти отсортированных данных), затем эффективно
  сливает runs. Сложность: O(n log n) в худшем случае, O(n) на уже
  отсортированных или почти отсортированных данных.
- **Стабильность** — Timsort **стабилен**: элементы с одинаковым ключом
  сохраняют относительный порядок, который был во входных данных. Это
  позволяет делать многоступенчатую сортировку последовательными вызовами
  `sort()` по разным ключам (сначала по вторичному критерию, потом по
  первичному) — классический вопрос на понимание стабильности.
