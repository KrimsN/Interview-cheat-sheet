# Модуль `itertools`

## Что нужно знать

Функции `itertools` реализованы на C, ленивые (возвращают итератор, а не
список) и заменяют собой типовые ручные циклы — на собеседовании полезно
уметь узнавать паттерн "вот тут напрашивается itertools" в чужом коде.

- **`chain(*iterables)`** — последовательно проходит несколько итерируемых
  объектов как один, без создания промежуточного списка (в отличие от
  `list1 + list2`).
- **`islice(iterable, start, stop, step)`** — срез по итератору (обычные
  срезы `it[a:b]` для итераторов не работают, см. раздел
  [Итератор](../python.md#итератор) в python.md, где это отдельно отмечено
  как ограничение).
- **`groupby(iterable, key)`** — группирует **соседние** элементы с
  одинаковым ключом. Частая ловушка: `groupby` не сортирует данные сам —
  если нужно сгруппировать одинаковые ключи по всей последовательности
  (а не только идущие подряд), данные нужно предварительно отсортировать
  по тому же `key`.
- **`product`, `permutations`, `combinations`** — декартово произведение,
  перестановки и сочетания без ручных вложенных циклов.
- **`count`, `cycle`, `repeat`** — бесконечные итераторы (по числам,
  по кругу, по одному значению) — обычно используются вместе с `islice`
  или условием останова, чтобы не уйти в бесконечный цикл.
